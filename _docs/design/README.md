This folder contains design references created with Google Stitch. `screens/` holds the PNG screenshots. `stitch/` holds the sample HTML. The same filename is used in both folders.

Each name below maps to the section of `_docs/specs.md` that the screen represents.

- `01 - Explore Routes - desktop` — map and filterable route list. Section 3.1 Discovery.
- `02 - Route Detail - desktop` — one route, with elevation profile, map, hazards, a transit sample, and gear. Section 4.7 Map and visualization. The plan action on this screen leads into section 3.2.
- `03 - My Trips - desktop` — saved plans, plan runs, share link, and delete. Section 3.3 Trip dashboard.
- `04 - Trip Planner - desktop` — the finished plan: recommendation, data completeness, transit, gear, and weather. Section 3.2 Plan a trip. The panels on this screen illustrate sections 4.3 Weather and hazards, 4.4 Public transport, 4.5 Gear guidance, and 4.6 Planning recommendation.
- `05 - Route Wiki - desktop` — maintainer review queue and revision diff. Section 4.8 Wiki-style editing.
